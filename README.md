# joel.cafe

Sitio personal de joel.cafe — apps funcionales para negocios, hechas con IA y café.

## Publicar en GitHub Pages

1. Sube el contenido de esta carpeta a tu repositorio (la raíz).
2. El archivo `CNAME` ya incluye `joel.cafe` — GitHub Pages lo toma automáticamente.
3. En tu DNS, apunta `joel.cafe` a GitHub Pages (registros `A` a las IPs de GitHub o `CNAME` a `tu-usuario.github.io`).
4. En Settings → Pages, activa **Enforce HTTPS**.

## Estructura

- `index.html` — página principal
- `css/styles.css` — estilos
- `js/main.js` — interacciones (menú, animaciones)
- `assets/img/` — imágenes, logo y códigos QR
- `404.html` — página de error amigable
